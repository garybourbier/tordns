# TorDNS — règles pour les agents

Le chantier en cours est décrit dans `docs/missions/00-lire-moi.md` : le lire en entier
avant toute mission, puis le fichier de la mission demandée (`docs/missions/NN-*.md`).

- Aucun secret ni adresse `.onion` de production dans le dépôt.
- Commit local sur `master` seulement : ni push, ni déploiement, ni connexion à un serveur de Gary.
- Chaque mission finit par `scripts/verifier-mNN.sh` ; ce qui n'est pas prouvé est écrit comme tel.
- Blocage après trois essais : l'écrire dans `docs/missions/journal.md` (« à confier à Claude »).
