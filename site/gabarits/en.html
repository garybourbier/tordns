Private, verifiable, community DNS

DNS that does not lie to you.

TorDNS encrypts your DNS queries inside Tor and hands them to a network of volunteer nodes. Your local resolver, your ISP and Wi-Fi networks no longer see the names you visit. A bounded cache, DNSSEC and signed updates complete the design.

Download TorDNS Understand it in a minute

Who it is for, and what it fights

Censorship

When a network blocks or hijacks public resolvers, TorDNS goes through Tor and hands resolution to a node chosen by the community.

Lying DNS

DNSSEC answers are checked on the client. A missing or invalid signature is refused instead of being served silently.

Privacy

No query logs on nodes, no tracker on this page. The cache is bounded and counters are aggregated.

Run a node

A node is a small VPS or a machine at home. It serves a Tor onion service and publishes no port on the Internet. Plan for about 1 GB of RAM.

git clone https://github.com/garybourbier/tordns.git && cd tordns && sudo ./noeud/installer.sh

To use the multi-arch images published on GHCR, place images.txt next to noeud/ and add --images ghcr: every image is pinned by its @sha256 digest. Without that option, images are built locally.

  • Core: the project’s public reference onion service.
  • Community: instances admitted after availability and honesty probes.
  • Node installation guide and GHCR images.

Security and limits, without overpromising

What is verified

Binaries are built by CI from the repository, checksums and attestations are published, the update manifest is signed with Ed25519, and DNSSEC answers are checked on the client.

What is not

The project has not had an independent audit. A volunteer running a node can log the queries it receives. Tor protects the network path, not against a malicious node.

Your part

DNSSEC depends on the queried zone. A domain without DNSSEC remains exposed to a lying resolver. TorDNS reduces DNS leaks; it does not by itself make your browser anonymous.

To report a vulnerability, use GitHub private reporting, never a public issue. See SECURITY.md.

Source code, licence, contributing

TorDNS is free software under the MIT licence. Code, missions and evidence live in the GitHub repository. Feedback and fixes go through issues; contributions must contain no secret, no real .onion address, and must include executable evidence.
